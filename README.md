# 🚀 Personal Portfolio Website

A modern, responsive personal developer portfolio showcasing my software engineering projects, technical skill set, and professional background. Built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite** for high performance and clean UI design.

---

## ✨ Features

- **Responsive Design**: Seamlessly adapts to mobile, tablet, and desktop viewports.
- **Project Showcase**: Highlighted web applications, full-stack projects, and system software with live links and repository references.
- **Skills Matrix**: Categorized overview of languages, frameworks, databases, and core software engineering practices.
- **Interactive UI**: Smooth scrolling, modern styling, and intuitive navigation.
- **Contact Info**: Direct communication channels and social links.

---

## 🛠️ Tech Stack

- **Frontend**: [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Version Control**: Git & [GitHub](https://github.com/)
- **Deployment**: Vercel / GitHub Pages
